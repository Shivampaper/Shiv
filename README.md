# Obsidian Deck • 10-Foot UI for Samsung Smart TVs

An ultra-refined, minimalist 10-foot Living Room UI designed specifically for **Samsung Smart TVs (Tizen OS / 4K Neo QLED)**.

Crafted with **Instrument Serif** and **Manrope** typography, warm brass accents, and full remote-control D-Pad spatial navigation.

---

## 📺 Live Features

* **Spatial D-Pad Navigation:** Built for the Samsung TV SolarCell remote (Left, Right, Up, Down, Enter, Back).
* **Deep Screen Design:** Deep ink/slate background (`#06080B`) optimized for Mini-LED and OLED contrast without backlight bleed.
* **Orchestrated Reveal:** Smooth rise animations and fluid rail scrolling with `translate3d`.
* **Zero Disruption for Others:** Runs as a single quick shortcut tile on the Samsung Home Bar, leaving all standard apps and the "For You" section untouched for other household members.

## 🚀 1-Click Deployment (GitHub Pages)

1. Push this repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/<YOUR-USERNAME>/<REPO-NAME>.git
   git branch -M main
   git push -u origin main
   ```
2. Go to your repository on GitHub:
   * **Settings $\rightarrow$ Pages**
   * Under **Build and deployment $\rightarrow$ Branch**, select `main` and root `/`.
   * Click **Save**.
3. Your permanent 24/7 TV URL will be:
   $$\mathbf{https://<YOUR-USERNAME>.github.io/<REPO-NAME>/}$$

## 🛠️ Remote Control Keys

| Key | Action |
| :--- | :--- |
| **◀ Left / ▶ Right** | Slide active rail tiles |
| **▲ Up / ▼ Down** | Switch between *Play* and *Inputs* rows |
| **Select / OK** | Launch highlighted app or input |
| **Back / Return** | Toast notification / dismiss |
| **Double Click / Tap** | Toggle borderless fullscreen |
